# Playwright Visual Qa

## Workflow
Set up Playwright projects for Chromium at 1920, 1440, 1366, 1024, 768, 390 and 360 widths. Screenshot/record homepage preloader, hero, carousel, historical collage, quiz, cursor, text hover, warp on non-home, player modal, tables, charts and export. Test route back/forward, keyboard focus, Esc, reduced motion, no horizontal overflow, quick clicking, console errors, missing assets and duplicate player IDs. Compare with local video reference frames, do not fake pixel-perfect evaluation when frames are too dissimilar. Run smoke, regression and Lighthouse-like budgets where available.
## Exit gate
Attach tests, actual run counts, screenshots/videos, failures and fixes; no untested 'complete' claims.
