# khiladi-ipl-media-integrity

Use only existing canonical IDs and portraits linked by official IPL pages. Inspect identity, alpha channel and source proof. Generated jersey/name graphics are not portraits. Record permission separately from source authenticity. Do not re-edit or publicly distribute protected media without confirmed rights. Missing media is an explicit gap; never substitute generic cricket as RR.

Use the existing isolated checkout; do not create worktrees unless explicitly requested. Never publish or deploy without authorization.
