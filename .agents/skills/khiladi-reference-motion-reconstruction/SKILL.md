# khiladi-reference-motion-reconstruction

Inspect live websites and supplied recordings. Capture start, intermediate, end and reverse states at matched viewports. Store observations, geometry and timing under docs/qa/reference-fidelity. Label observed, inferred and unavailable evidence separately. Never call visual parity complete from compilation or a static overlay.

Use the existing isolated checkout; do not create worktrees unless explicitly requested. Never publish or deploy without authorization.
