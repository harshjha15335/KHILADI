# Rr Brand Design System

## Workflow
Audit official RR brand references for inspiration; distinguish genuine official colours from provisional proposal. Design original interfaces, not an officially affiliated replica. Start with `#E81274` pink, `#101B4B` navy, `#29134F` purple, `#F7F4FA` white, and `#D6AF60` gold; refine with accessible contrast measurements. Use Space Grotesk / Inter / JetBrains Mono or suitably licensed replacements. Implement tokenized CSS variables, semantic colour meanings, component specifications and breakpoints. Build dark and light surfaces, clear focus rings and table-legible typography. No coffee palette.
## Deliverables
`docs/design/BRAND_GUIDE.md`, tokens CSS, component storybook/example gallery, contrast validation outputs.
## Exit gate
All pages unmistakably share one original RR-inspired identity; numeric tables and small text pass colour contrast requirements.
