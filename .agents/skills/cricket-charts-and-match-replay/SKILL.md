# Cricket Charts And Match Replay

## Workflow
Define consistent units, sample-size gates, reference lines, confidence bands, actual vs predicted tooltips and visual legends. Build pressure-lab pre-ball timeline, innings/over delivery scrubbing, match-state chart and win probability only when trained model exists. Reuse actual event IDs; do not invent 2008 or 2022 event details. Optimize scrubber update using overlay or targeted ECharts updates rather than full chart rerender. Provide table alternatives for all meaningful charts.
## Exit gate
Match replay reconstructs source balls accurately and labels model probability, known events, and any uncertainty.
