# Competition Report And Exports

## Workflow
Generate two ordered ten-player lists from the real pressure model, with exact IDs/names from the supplied CSV, confidence, matches, eligibility and reasons. If verified dropdown full list available, assert membership; otherwise label dropdown verification incomplete and require human confirmation. Generate a reproducible methodology document/PDF from model artifacts, no hand-entered scores. Cross-validate export, report and UI rankings; keep underlying restricted data private. The site is optional competition support; mandatory submission deliverables take priority.
## Exit gate
Report and rankings have 1:1 match for names, IDs, rank order and method version; no claim of Unstop submission without confirmation.
