# khiladi-cricket-analytics

Preserve backend models, source data and top-ten outputs. Present simple summaries first and actual stored metrics under disclosure. Missing measurements are unavailable, never invented fallback scores, prices, matches or confidence. Label model scores as estimates and pressure aggregates as pressure, not death-over evidence.

Use the existing isolated checkout; do not create worktrees unless explicitly requested. Never publish or deploy without authorization.
