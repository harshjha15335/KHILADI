# Section comparison

The five `*-comparison.mp4` files pair supplied recordings with actual Chromium captures at matching native viewport dimensions. They are diagnostic comparisons with approximate event alignment, not claims of pixel-exact parity. Source coffee/agency/AI scenes are intentionally not shipped as KHILADI assets. Paired PNGs and 50% overlays are provided locally; a pixel-difference percentage would be misleading with different subjects, fonts and brand colours.
