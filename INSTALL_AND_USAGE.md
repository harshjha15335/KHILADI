# ROYAL EDGE — Antigravity Project Skills v2

This bundle contains **21 project-specific `SKILL.md` modules**, 1 always-on `AGENTS.md`, and a player-ID validation script. They are authored task workflows, not claims that identical official Antigravity skills already come preinstalled.

## Install into Antigravity project
Unzip and copy the folder contents into your workspace root so you have:
- `<project-root>/AGENTS.md` (merge if one already exists)
- `<project-root>/.agents/skills/<skill-name>/SKILL.md`
- `<project-root>/.agents/skills/player-whitelist-integrity/scripts/verify_csv_players.py`

If your Antigravity installation uses a different skills path, follow the product's current skill-loading instructions. Do not overwrite existing rules without reviewing conflicts.
